# toyinog.com portfolio

## What we build
A personal portfolio website for Toyin Ogunseinde at toyinog.com. It replaces the earlier toyinog-website code when it goes live. Everything else (audience, sections, content, look, stack, hosting) is decided with Toyin in `/scope` and `/architect`, not assumed here.

## Phases
- **P0 Scope:** the lead runs `/scope` with Toyin, one question at a time, until every feature has acceptance criteria. Toyin approves the scope.
- **P1 Stack:** the lead runs `/architect` for the stack, hosting and design direction (Mobbin references required), then plans the scaffold task: app skeleton, CI workflow (lint, typecheck, test, build) and `/audit` to write AGENTS.md.
- **P2 onward:** feature phases from the approved scope, one task per PR.

## Kickoff message to the lead
"Read plan.md and CLAUDE.md. Run /scope with Toyin for the portfolio, asking one question at a time. When Toyin approves it, run /architect for the stack, then create a board for P1 and assign it."
